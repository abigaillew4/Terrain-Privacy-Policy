Privacy Policy for VFI Terrain

Last Updated: October 18, 2026

Introduction

Terrain is an internal audit application intended exclusively for authorized VisionFund personnel. This Privacy Policy explains how the application accesses, stores, and uses information collected during audit activities.

By using Terrain, authorized users acknowledge and agree to the practices described in this Privacy Policy.

Authorized Use

Terrain is intended solely for authorized VisionFund audit personnel.

Access to the application is restricted through an authorization code and is not intended for use by the general public.

Information Processed by the Application

The application may collect, record, and store the following information:

  • Audit responses entered by users.
  • Interview observations and notes.
  • Borrower and loan information used for audit purposes.
  • Photographs captured using the device camera.
  • GPS coordinates associated with interview and audit activities when location permission is granted.
  • Interview metadata, including:
    • Interview date
    • Interview start time
    • Interview end time
    • Auditor information
    • Interview status
  • Files created through reporting and export functionality.

How Information Is Used

Information collected through the application is used exclusively for:

  • Conducting internal audit activities.
  • Documenting audit findings.
  • Supporting compliance and monitoring activities.
  • Recording evidence associated with audits.
  • Internal reporting and quality assurance.
  • Maintaining organizational audit records.

Data Storage

Information processed by the application is stored locally on the device.

The application does not automatically transmit audit information, photographs, GPS coordinates, or interview data to external servers.

Data remains on the device unless an authorized user chooses to export or share information.

Deleting application data or the local application database may permanently remove stored audit information from the device.

Data Sharing

The application does not sell personal information.

The application does not share collected information with advertisers, analytics providers, or unrelated third parties.

The application includes functionality that allows authorized users to export files and use the Android sharing system. Any sharing of exported information is initiated and controlled entirely by the user.

Information may be accessed by the organization operating the application in accordance with internal audit and compliance processes.

Permissions Used

Location Permission

The application may request access to the device's location in order to record GPS coordinates associated with audit interviews and field activities.

Location information is collected only when permission has been granted by the user.

Camera Permission

Camera access is used to capture photographs that support audit documentation and verification activities.

Storage and File Access

File access is used to:

  • Import audit-related files.
  • Export audit reports and supporting information.
  • Store photographs and audit documentation on the device.

Security

Reasonable administrative and technical safeguards are used to help protect audit information stored by the application.

Users are responsible for maintaining the security of devices used to conduct audit activities.

Children's Privacy

Terrain is not directed toward children and is intended solely for use by authorized organizational personnel.

Changes to This Privacy Policy

This Privacy Policy may be updated from time to time. Any updates will be reflected by revising the "Last Updated" date at the top of this page.
